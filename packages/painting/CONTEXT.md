# Painting

HamsterNote 的画布绘制包：提供 DrawingSurface 组件及其工具（笔、形状、套索、文字、橡皮）、视口变换与虚拟纸渲染。

## Language

### 选区

**选框（Selection Box）**:
套索或文字工具建立选区后渲染的可视边框及其手柄。
_Avoid_: 选择框、选区边框、蚂蚁线（蚂蚁线只是选框的一种视觉样式）

**命中区（Hit Area）**:
选框边缘用于拖拽调整的透明加宽描边区域，是交互属性而非视觉装饰。
_Avoid_: 热区、点击区

### 尺子

**尺子（Ruler）**:
位于画布宿主上的可操作无限长条。尺子逻辑原点、旋转角、高度和物理刻度采用宿主局部 CSS 像素或弧度；视觉层由宿主裁剪、位于 Minimap 下方，并延伸到任意移动或旋转都看不到端点。画布视口平移或缩放不会改变尺子的屏幕几何。尺子上下对称显示毫米、半厘米和厘米三级刻度，不显示文字。
_Avoid_: 画布尺子、随视口尺子

**尺子平移（Ruler Translation）**:
直接改变尺子的逻辑原点，同时保持高度和方向不变。沿尺子轴向平移会改变刻度相位，垂直轴向平移会改变长条位置；画布视口平移不属于尺子平移。
_Avoid_: 尺子变换（仅指位置变化时）

**尺子旋转（Ruler Rotation）**:
鼠标左键从尺子命中区内按下并配合 `Alt` 拖动时，以尺子中线在画布可视区域内裁切段的中点为固定旋转中心，尺子逻辑原点随尺子刚性旋转；两个归属于尺子的触点仍按原有 multi-drag 语义同时改变逻辑原点和方向。鼠标旋转角度提示固定在上述裁切段中点；触摸旋转角度提示随手势更新，始终位于当前两指中点向当前尺子中线的投影点。两种输入仅在进入 45° 倍数附近的角度容差范围时吸附，范围外保持自由旋转。
_Avoid_: 绕画布中心旋转

**尺边绘制约束（Ruler Edge Drawing Constraint）**:
绘制手势开始时按起点所在侧选择距离最近的物理尺边。指针尚未跨过该边时保持原始轨迹；跨过后，原始指针位于尺子条带内时投影到当前选中的尺边。指针离开条带时，该离尺样本保持原始轨迹，并按落点所在侧重新等待下一次进入；同一绘制手势再次进入时，可吸附到新接近的物理尺边。稀疏采样直接跳过整个条带时不补造中间吸附点。
_Avoid_: 即时尺边吸附、尺身内部动态换边、永久释放

**触点归属（Touch Ownership）**:
每个触点分别归属于它开始接触时命中的可交互对象。一个对象只使用归属于自身的触点判断手势，不占用其他对象上的触点。
_Avoid_: 整组触摸归属

**抓取偏移（Grab Offset）**:
拖动开始时，操作对象中心与指针或多触点中点之间的位置差。拖动期间保持该位置差，可避免对象在手势激活时发生跳变。
_Avoid_: 拖拽偏移、吸附偏移

**并发手势（Concurrent Gestures）**:
分别归属于不同对象的触点可以同时驱动各自对象。任何一方都不因另一方开始响应而冻结或接管其触点。
_Avoid_: 组合手势、共享手势

### 渲染语义

**屏幕恒定线宽（Screen-constant Stroke）**:
无论视口缩放如何，在屏幕上呈现恒定像素尺寸的描边语义。选框与手柄的可见线宽、选框及套索预览的虚线段长与间隔属于此类。
_Avoid_: 固定线宽、不缩放线宽

**画布距离（Canvas Distance）**:
以画布坐标计量的长度语义，随视口缩放产生视觉变化。命中区宽度属于此类。
_Avoid_: 逻辑像素、世界坐标长度

**虚拟纸模式（Virtual Paper Mode）**:
由 virtual-paper 容器接管视口变换的渲染模式，与 SVG 内部变换的非虚拟纸模式相对。
_Avoid_: VP 模式（口头缩写，不落入文档）
