# 选框线宽语义：屏幕恒定线宽与画布距离分离

开启 virtual-paper 时，视口缩放由容器的 CSS transform 实现，SVG 的 `vector-effect="non-scaling-stroke"` 对其无效，导致套索与文字选框的视觉描边随缩放变化。我们决定**移除对 `non-scaling-stroke` 的全部依赖**，选框与手柄的可见线宽，以及选框和套索预览的虚线段长与间隔，统一改为屏幕恒定语义（数值按视口缩放补偿），一条代码路径同时覆盖虚拟纸与非虚拟纸两种模式。

## Considered Options

- **统一数值补偿（采纳）**：一条路径覆盖两种模式，不存在「虚拟纸下忘了补偿」的死角；可见描边均保持屏幕恒定，命中区则继续采用画布距离语义。
- **仅虚拟纸模式打补丁**：保留 `non-scaling-stroke`，虚拟纸激活时切换为数值补偿。对现有行为零触碰，但同一块选框出现两套线宽逻辑，新增控件时容易漏掉其中一条路径。

## Consequences

- **虚线段长与间隔采用屏幕恒定语义**：套索预览、套索选框和文字选框均按 `4 / viewport.scale` 设置画布长度，使每段虚线与间隔在屏幕上保持 4px。命中区宽度仍刻意保持画布距离语义（不补偿），因此会随视口缩放产生视觉变化。术语分界见 `packages/painting/CONTEXT.md`。
- 命中区不做下限保护：视口缩到很小（如 0.25×）时，文字选框边缘命中区在屏幕上只剩约 3px，点中难度上升，已被接受。
- 既有测试断言 `vector-effect="non-scaling-stroke"` 需同步移除，并新增线宽、虚线段长及间隔在缩放与虚拟纸模式下的回归测试。
