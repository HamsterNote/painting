# HAM-245：段级预筛与原版性能下限

## 实现与冻结提交

本轮产品修改仅为段级预筛和内部诊断钩子，冻结查询版本 `8e89871ef449f6e637d29cd828a30ab6cbf10651`，原版 `81bff35`。旧 `queryObjectLasso`、布尔相交谓词和共线方向积行为未改；未改调度、采样、选区语义或100ms/2T阈值。设备支线未推进，不将含P2的f4453ab用于最终结论，等待负责人另行冻结设备待验SHA。

保留原快速包含判断，保证“边界不相交但对象/套索互相包含”的命中不丢失。边界扫描仍先执行旧方向积判定，保留共线分离误命中；随后用对象边bounds按margin膨胀，与实际规范化套索的逐段bounds作闭区间重叠检查。已有扫描中记录是否存在重叠，不增加第二遍边界遍历。没有重叠且未命中则直接判否。对于重叠段，追加套索无限直线与膨胀对象边框的分离证明：四个角点的方向值都严格同号才排除；每步减法/乘法使用向外舍入的区间包络（含subnormal保护），不设可调epsilon。包络含零或非有限运算无法证明分离，仍调用旧布尔谓词；此证明只用于缩窄负判定后的回退，不替代既有共线/接触正判定。已证明简单的原始环才启用直线分离证明；发生自交/接触而进入旧canonicalizer的环保留AABB重叠回退。原因是规范化可能生成接触组件及孔，其全环绕数与旧布尔相交的数值解释不一致，边界分离不能单独排除布尔内部命中。非有限/无法判断情形保守回退并单列indeterminate原因，不能冒充已证明分离。

诊断钩子为内部可选参数；普通产品调用不读取新增计时器、不记录回退事件。独立诊断轮按objectId去重计回退候选，避免多piece重复计数；记录每次旧谓词墙钟耗时、对象kind/顶点数、回退原因及实际prepared多边形。几何dump发生在查询结束时间戳之后。
