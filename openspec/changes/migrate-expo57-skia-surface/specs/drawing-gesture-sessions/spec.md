# Spec Delta

## Purpose

规定不依赖 multi-drag 的领域手势会话行为：绘图笔的单指与二指导航仲裁及取消处理、尺子的抓取偏移与角度吸附及双指刚体变换（**仅平移 + 旋转，不缩放**）、以及选区的移动、缩放与旋转，并确保运行时完全移除对 multi-drag 的依赖。

## ADDED Requirements

### Requirement: 完全无 multi-drag 运行时依赖

手势会话实现 MUST 不引用 multi-drag 及其 core 包作为运行时依赖，MUST 自包含地实现绘图、导航、尺子与选区所需的多指语义。

#### Scenario: 无运行时引用

- **WHEN** 检查应用的运行时依赖与打包产物
- **THEN** 不存在对 multi-drag 及其 core 包的引用

#### Scenario: 功能不依赖该库

- **WHEN** 用户执行绘图、导航、尺子或选区操作
- **THEN** 这些行为由自包含的手势会话实现，不依赖 multi-drag

### Requirement: 笔单指与二指导航仲裁

笔工具下，单指绘制与世界级二指导航 MUST 被明确仲裁：单指进行绘制，二指进行导航且 MUST NOT 产生笔迹；指针被取消时 MUST 干净终止当前会话并丢弃未提交的临时笔迹。

#### Scenario: 单指绘制

- **WHEN** 笔工具下用户以单指触摸并移动
- **THEN** 生成笔迹而不触发视图导航

#### Scenario: 二指导航不留下笔迹

- **WHEN** 笔工具下用户以二指触摸并移动
- **THEN** 视图发生导航，且不产生任何笔迹

#### Scenario: 指针取消

- **WHEN** 绘制过程中指针被取消
- **THEN** 当前会话干净结束，未提交的临时笔迹被丢弃且不污染文档

### Requirement: 尺子抓取偏移与角度吸附

尺子工具 MUST 保留抓取点相对尺子的偏移，使用户拖动时尺子不跳变；角度 MUST 吸附到 45 度增量，且吸附 MUST 在交互过程中即时可见。

#### Scenario: 抓取不跳变

- **WHEN** 用户从尺子上任意非中心点开始拖动
- **THEN** 尺子保持该抓取偏移跟随指针，不发生位置跳变

#### Scenario: 角度吸附

- **WHEN** 用户旋转尺子到接近某一 45 度倍数的角度
- **THEN** 尺子角度吸附到最近的 45 度增量并即时反映在界面上

### Requirement: 尺子双指刚体变换（仅平移 + 旋转，无缩放）

尺子工具 MUST 支持双指刚体变换，且变换 MUST 为**仅平移 + 旋转**的一致组合，MUST NOT 引入缩放或任何非刚体形变。尺子高度、刻度间距、PPI 与无限长条几何保持不变；「比例保持一致」只表示无形变，不是新增尺子 scale 自由度（见 `decisions/task-4-gesture-session-boundaries.md`）。

#### Scenario: 双指平移旋转（不缩放）

- **WHEN** 用户以双指对尺子执行平移与旋转操作
- **THEN** 尺子以刚体方式一次性变换到对应位姿，尺子长度、刻度间距与比例保持不变、无形变，且**不产生缩放**

#### Scenario: 变换中吸附

- **WHEN** 双指刚体变换过程中尺子角度接近吸附阈值
- **THEN** 角度吸附仍然生效且不破坏刚体平移/旋转变换

### Requirement: 选区移动缩放旋转

选区 MUST 支持移动、缩放与旋转，且变换 MUST 以选区自身的世界坐标锚点为准，变换后其内部对象几何 MUST 与选区一致更新。

#### Scenario: 移动选区

- **WHEN** 用户拖动选区
- **THEN** 选区内所有对象随选区一起平移，相对几何保持不变

#### Scenario: 缩放选区

- **WHEN** 用户缩放选区
- **THEN** 选区内对象按选区缩放比例更新，且缩放锚点保持稳定

#### Scenario: 旋转选区

- **WHEN** 用户旋转选区
- **THEN** 选区内对象随选区旋转，相对几何与命中结果保持一致
