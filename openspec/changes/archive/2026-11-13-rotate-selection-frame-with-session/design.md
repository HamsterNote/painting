# Design

## Context

动机见 proposal.md。当前 main 为 schema3 分层编辑器；`SelectionOverlay.tsx` 按 preview/document 的 `visualWorldBounds` 每次重建世界 AABB，`layeredToolSession.ts` 围绕所选对象的 AABB 中心构造旋转或等比缩放。`semanticWebAdapter.ts` 将 client 坐标经页面映射及 viewport 逆变换交给工具会话。

已读取 PR #51 的共享 `layeredSelectionGeometry.ts` 及完整规格：其 frame、resize、rotate、region 由同源模型提供，region 为包含手柄的宿主正交矩形，且整体选区优先于普通对象命中。本提案改变该矩形的方向语义，保留其外扩带与优先级。PR 仍 OPEN，实施前需集成前置；不要转而修改旧 V2 `selectionFrame.ts` / `selectionOverlay.ts`，它们不是当前 schema3 UI 的调用路径。

## Goals / Non-Goals

**Goals:** 让会话几何成为显示和命中的唯一来源，保持文档、页面、宿主坐标分工；使预览、提交、取消及生命周期可验证。

**Non-Goals:** 不计算最小面积包围盒、不为每种对象推断自然朝向、不引入非等比缩放或新手柄、不修改文档 schema、撤销历史结构、套索精确选择算法或原生绘图路径。

## Decisions

### 1. 以会话起始框和累计变换保存方向

在 controller 的临时交互状态中持有选择会话标识、稳定对象集合、起始文档轴对齐框及累计框变换；通过独立交互通知或现有临时频道驱动 overlay。具体类型名可在实施时确定，不改变公开 selection 的对象 ID 数组契约。按集合内容而非数组引用判断会话是否改变。

新会话从当前可见几何的保守 AABB 开始，包含描边并沿用退化几何保护。每个选择手势冻结操作前的框和对象原始变换；将同一个移动/中心等比缩放/中心旋转增量分别组合到对象与框上。预览基于手势起点状态计算，避免逐帧累乘漂移；完成后保存累计框变换，取消则恢复手势前状态。旋转用相邻角度差解包，跨 ±π 不跳变；继续保留原有中心缩放契约，不改为角点锚定。

不每帧重算变换后对象的世界 AABB，也不取某个对象的 transform 角度作为整体方向：前者会丢失方向并膨胀，后者无法覆盖多选或既有不同朝向对象。

### 2. 扩展 #51 的共享几何，在框局部空间精确命中

共享模型提供框四角、局部到宿主变换及其逆、现有右下缩放手柄、旋转手柄和局部完整优先矩形。旋转手柄沿局部上边法线偏移；缩放方块的形状和命中区随框旋转，圆形旋转手柄仅需同步其中心。保留当前手柄数量、尺寸/容差策略与线宽语义，不借此次变更统一旧 ADR 与新路径的尺寸策略。

在选框局部空间包围框和手柄得到完整 region，映射后呈现为有方向的矩形。命中将宿主点逆变换到同一局部空间，依次判断旋转手柄、缩放手柄、完整 region；region 的宿主 AABB 只可用于粗筛。保留 #51 的外扩带空白整体拖动能力，不缩小为可见边框内部。overlay 的 SVG transform、适配器起点命中及输入仲裁使用同一模型，不各自重算。

### 3. 页面旋转只参与坐标复合

使用现有 `pageCoordinates.ts` / `affine.ts`，遵循 client → 页面/宿主局部 → viewport 文档坐标 → 框局部的逆映射，正向显示按相反顺序复合。选框状态记录文档中的方向；页面 90° 旋转或外层 CSS 旋转不改变会话角度，不新增 viewport 旋转字段。以实际宿主已有映射路径为准，避免页面映射与 CSS 变换重复应用。非法或不可逆映射拒绝操作，不退回未经映射的正交命中。

### 4. 明确状态失效边界和事务归属

本方案的合理假设（非用户逐条确认）：选择集合变化是新会话；同集合重复设置与 viewport 更新不是。外部文档替换或 undo/redo 后，对仍有效选择重建正交框；无需持久化或追溯 UI 角度历史。这能避免外部内容更新留下不可见命中区，已写成可验收行为。

会话自己的提交有明确来源，应原子发布文档更新与最终框状态，不能被普通 document 订阅误判为外部替换而重置角度。取消保留既有选择时回滚到操作前框；清空选择、销毁 controller 或卸载清理时销毁旧会话。工具/输入方式切换按既有取消契约清理，保留对象数据与历史。非 owner 不改变框状态，迟到事件必须核对会话标识。

## Risks / Trade-offs

- [#51 尚未进入 main；与 #52 套索性能改动相邻] → 集成后核对 `begin/end/cancel` 与输入仲裁，复跑两个前置的相关回归；本次不做合并或实现。
- [文档通知先于框状态导致松手闪回正交] → 原子更新或提交来源标识，补充松手后渲染断言。
- [再次计算世界 AABB 导致框变大] → 基线框只在新会话或明确外部失效时建立，后续使用同一增量变换。
- [页面和框旋转重复计算] → 用带非零平移、多个 zoom、四种页面方向的真实 pointer 测试验证显示/逆映射。
- [临时状态触发全历史重绘] → 状态通知只驱动选框与必要 preview，保持 #52 的历史层隔离。
- [历史后重建框会改变方向] → 明确为本方案的边界行为；对象历史仍完整，避免为纯 UI 状态新增事务。

## Migration Plan

实施前先集成 HAM-246 / #51 的代码和规格，并保留 main 的 #52；然后扩展其共享几何与会话状态，接入显示与输入。无需文档迁移或新依赖。回滚未来实现时整体回退会话状态、显示和命中改动，保留 #51 原有正交整体拖动能力。文档增量同步/归档由后续流程执行，当前阶段不执行。
