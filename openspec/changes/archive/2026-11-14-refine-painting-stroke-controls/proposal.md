# Proposal

## Why

HAM-258 的截图暴露了缩放滑条使用浏览器默认黑轨蓝柄、笔宽输入占据首层且笔触设置分散的问题。用户需要从一个可预览笔触的入口完成设置，并确保新建画板真正默认黑色。

## What Changes

- 新编辑器自由笔、形状均选中首个黑色 `#2D2D2D`，首次新笔画使用相同颜色。已有规格及 `createEditor.ts` 已要求／设置黑色，本次验证实际入口与状态传播；不把挂载时强制重置颜色当修复。
- 重做缩放 popover 滑条视觉：6px 圆角浅灰轨道、紫色已填充段、18px 白色紫边滑块、独立焦点环，44px 高交互区。保留 25–800%、步长 25、百分比读数、72px 稳定入口及视区中心锚定。
- 用紧跟工具菜单的「笔触设置」按钮替换首层笔宽输入。按钮显示随当前工具族颜色和笔宽变化的 S 型曲线；极值采用有界视觉映射，真实值由菜单数值呈现。
- 新笔触菜单依次收纳笔宽（标签、滑条 + 右侧数值输入同一行，0.5–200、步长 0.5）、颜色（标签与完整六色预设、自由取色环同一行）、不透明度、自由笔压力模式或形状线型。笔宽／颜色／不透明度／压力标签左边缘同列对齐；删除色板下方独立「自定义颜色」行，inlinePickers 的十六进制输入并入颜色分区且保留键盘入口。一般设置只保留输入模式、尺子、虚拟纸张、小地图。
- 底部栏原颜色区整体移入笔触菜单，原位置不留占位、复制入口或新功能；移除末尾多余分隔线，胶囊自然收窄。其他工具禁用笔触按钮并说明用途。
- 保留独立工具族参数、已有对象快照、撤销语义、宿主边界及键盘／触控可用性。

## Capabilities

### New Capabilities

无。

### Modified Capabilities

- `painting-toolbar`：更新首层分组、笔宽入口、设置归属与调色板位置；补充 S 曲线预览和缩放滑条的可验收视觉标准。默认黑色沿用既有要求并补充首次绘制回归。

## Impact

主要涉及 `packages/painting/src/layered/Toolbar.tsx`、`toolbarStyles.ts`、`ToolbarNumberField.tsx` 及工具栏相关单测／UI 测试；复用 `ToolbarPanel`／`ToolbarPopover`。`createEditor.ts` 仅在查明实际默认色链路缺陷时修正。无需新增依赖、公开 API 或文档格式迁移；DOM、Expo DOM/WebView 均需兼容，原生 PencilKit 工具栏重设计不在范围。

## 已确认范围与边界

- 第 3 条原文为空编号加同一截图，现经用户明确确认是截图中的笔宽数字输入框：从首层移入新菜单，保留直接数字编辑；该解释已不再是待确认假设。
- “黑色”指现有第一枚预设 `#2D2D2D`，不改为 `#000000`。截图绿色墨迹不证明当前版本仍有默认色错误；需用全新编辑器验证。
- “压力等”指现有压力四模式、不透明度及形状线型的迁移，不新增压力曲线编辑器、笔刷引擎或全局偏好存储。
- 视觉数值为本提案的设计决策；保留当前工具栏布局／安全区实现，不借此修改其他规格中的历史尺寸差异。

## 冒烟 / 自测用例

开发阶段执行；本次 propose 不声称以下用例已通过。Web 使用现有 `openLayeredEditor` 夹具与 `layeredState` 状态探针；触控／Expo DOM 另记录宿主及版本。每项记录通过／失败、截图或状态断言；不可用环境记为未验证，不冒充通过。

## 未决问题

无阻塞性产品问题。默认绿色的具体复现入口及实际设备验证由开发按 S1／S8 记录；若全新入口已正确，保留回归覆盖即可，不虚构修复点。
